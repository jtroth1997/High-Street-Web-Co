# High Street Web Co.

**Websites built for local business.**

High Street Web Co. creates smart, professional websites for small and local businesses. We keep the process straightforward, provide personal support from first chat to launch, and do not add unnecessary monthly hosting charges.

## What we offer

- New small-business websites
- Existing website redesigns
- Booking and appointment websites
- Portfolio and showcase websites
- Community and membership websites
- Mobile-first responsive design
- Friendly, jargon-free support

## Our promise

**One design and build price. No monthly hosting fees from us.**

Customers pay for the design and build of their website. We then provide clear instructions and support to get everything set up and live. The customer only needs to pay separately for their chosen domain name, which normally costs a small amount each year.

## Project

This repository contains the complete source code, styling, local fonts, build scripts and configuration needed to run and deploy the High Street Web Co. website.

### Run locally

```bash
npm install
npm run dev
```

### Production build

```bash
npm run build
```
